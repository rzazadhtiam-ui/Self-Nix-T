# 🚀 Getting Started

Self Nix commands can be used through their supported command forms.

Depending on the command, a feature may be available through:

- 🇮🇷 Persian command
- 🇬🇧 English command
- `/` Telegram Slash Command

### Example

The balance command can be used as:

```text
موجودی
balance
/balance
